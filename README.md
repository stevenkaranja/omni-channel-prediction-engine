# Omni-Channel Prediction Engine

Transformer-based demand forecasting system for luxury retail supply chains,
integrated with real-time POS data streams and AWS SageMaker.

## Results
- 94% forecast accuracy (vs 67% baseline)
- +$12.4M ARR optimised across 400 locations
- 60% reduction in dead-stock inventory

## Stack
Python · PyTorch · AWS SageMaker · Snowflake · Apache Kafka
